# Peptide Advisor Chatbot - Replit Build Instructions

## Project Overview

Build an AI-powered peptide education and recommendation chatbot that guides users through a personalized onboarding flow, then provides tailored peptide guidance based on their profile. The system should feel like talking to a knowledgeable friend, not a medical database.

**Primary Use Cases:**
- Users exploring peptides for the first time
- Users wanting to compare options for specific goals
- Users preparing questions for their healthcare provider

---

## Tech Stack Requirements

### Framework
- **Next.js 14+** with App Router (Edge-compatible)
- **Edge Runtime** for API routes (faster, works in app webviews)
- **TypeScript** for type safety

### Styling
- **Tailwind CSS** for responsive design
- Mobile-first approach
- Support for both light and dark modes

### AI Integration
- **OpenAI API** (GPT-4 or GPT-4-turbo recommended)
- Store API key in Replit Secrets as `OPENAI_API_KEY`

### Data
- Embedded knowledge base (JSON)
- No database required for MVP (stateless conversations)

## Knowledge Base Structure

Embed this as a JSON file that gets injected into the system prompt. Here's the schema:

```typescript
// types/peptide.ts

interface Peptide {
  id: string;
  name: string;
  aliases: string[];
  category_primary: string;
  categories_secondary: string[];
  mechanism: string;
  goals_addressed: string[];
  gender_notes: {
    male: string;
    female: string;
  };
  conditions_beneficial: string[];
  conditions_contraindicated: string[];
  dosing: {
    typical_range: string;
    frequency: string;
    timing: string;
    cycle_length: string;
  };
  administration: ('subcutaneous' | 'oral' | 'topical' | 'nasal')[];
  cost_tier: 'budget' | 'moderate' | 'premium';
  monthly_cost_range: string;
  side_effects: string[];
  crossover_benefits: string[];
  stack_synergy: string[];  // peptide IDs that work well together
  stack_redundant: string[]; // peptide IDs that are redundant
  timeline_to_results: string;
  research_status: 'FDA-approved' | 'clinical-trials' | 'research-stage';
}

interface UserProfile {
  intent: 'cosmetic' | 'medical' | 'both';
  experience_level: 'beginner' | 'intermediate' | 'advanced';
  gender: 'male' | 'female' | 'unspecified';
  life_stage?: string;
  conditions: string[];
  goals_ranked: string[];
  budget_tier: 'budget' | 'moderate' | 'optimal' | 'unlimited';
  administration_preference: string[];
}
```

## OpenAI Integration

### API Route (Edge Runtime)

```typescript
// app/api/chat/route.ts

import OpenAI from 'openai';
import { NextRequest } from 'next/server';
import { peptideKnowledgeBase } from '@/data/peptides';

export const runtime = 'edge';

const openai = new OpenAI({
  apiKey: process.env.OPENAI_API_KEY,
});

export async function POST(req: NextRequest) {
  const { messages, userProfile } = await req.json();

  const systemPrompt = buildSystemPrompt(userProfile, peptideKnowledgeBase);

  const response = await openai.chat.completions.create({
    model: 'gpt-4-turbo-preview',
    messages: [
      { role: 'system', content: systemPrompt },
      ...messages,
    ],
    temperature: 0.7,
    max_tokens: 1500,
  });

  return new Response(JSON.stringify({
    message: response.choices[0].message.content,
  }), {
    headers: { 'Content-Type': 'application/json' },
  });
}

function buildSystemPrompt(profile: UserProfile, kb: any): string {
  return `You are Pat, a knowledgeable and friendly peptide education assistant. Your role is to help users understand peptides and prepare informed questions for their healthcare providers.

## Your Personality
- Warm, approachable, never clinical or robotic
- Confident but not preachy
- You explain complex things simply
- You proactively mention crossover benefits users might not know about
- You always include cost estimates and side effects in recommendations

## User Profile
${JSON.stringify(profile, null, 2)}

## Knowledge Base
${JSON.stringify(kb, null, 2)}

## Response Guidelines

1. **Always personalize** based on the user's profile (gender, conditions, goals, budget)

2. **For recommendations**, always include:
   - Why it fits their specific situation
   - Mechanism (brief, accessible language)
   - Timeline to expect results
   - Monthly cost estimate
   - Common side effects
   - Any crossover benefits they'd appreciate
   - Questions to discuss with their provider

3. **For comparisons**, use markdown tables

4. **Stacking guidance**:
   - Recommend synergistic combinations
   - Warn about redundant pairings (e.g., "CJC-1295 and Sermorelin both work the same way—choose one")
   - Flag contraindications based on their conditions

5. **Contraindication alerts** (must always mention):
   - Cancer history: Avoid all GH-promoting peptides
   - Pregnancy: Recommend avoiding peptides
   - Specific condition conflicts from knowledge base

6. **Never**:
   - Provide specific medical advice
   - Recommend sources/vendors
   - Claim peptides can "cure" anything
   - Skip side effect disclosure

7. **Always end recommendations with**: "This is educational information to discuss with your healthcare provider. They can help determine if this is appropriate for your specific situation."

## Formatting
- Use markdown for structure
- Use tables for comparisons
- Use bullet points for lists
- Keep paragraphs short and scannable
- Use emoji sparingly for visual breaks (✅ ⚠️ 💡)`;
}
```

**How it works:**
CJC-1295 extends your natural GH release, while Ipamorelin triggers clean GH pulses (without the side effects of older peptides). Together, they create a synergistic effect that's greater than either alone.

**⚠️ One thing to discuss with your provider:** Since you mentioned insulin resistance, ask them about monitoring your fasting glucose during the first month. GH can affect blood sugar in some people.

## Error Handling

- **API failures:** Show friendly retry message
- **Rate limiting:** Queue messages, show "Pat is thinking..."
- **Empty responses:** Fallback to "Let me try that again..."
- **Network issues:** Offline indicator with cached conversation
